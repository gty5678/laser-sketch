# 照片标注行为与共享边界

## 文档

照片标注独立于毫米草图：`PhotoPoint` 使用原照片宽、高的归一化坐标，保持有限 Double 数值，不持有 Bitmap、Canvas、View 或图片文件路径。照片字节由平台负责，文档通过可选逻辑资产 ID 引用照片。

每个标注在所在照片文档中有独立 ID，分为尺寸、文字、角度和面积。尺寸保存两个端点与标签；文字保存位置、内容、大小档和白底；角度保存顶点及两射线点；面积保存至少三个顶点与标签。颜色使用平台无关 ARGB 整数，保留现有大小/线宽档位语义。尺寸与面积标签只是用户文字，不能把像素坐标当作毫米或自动推断真实面积。

旧 Android JSON 没有标注 ID，兼容导入按类型和索引赋予局部 ID。有限 Float 坐标扩为 Double 后可精确转换回原 Float；无效非有限坐标和少于三个点的面积被跳过。旧原件字段布局保持不变；统一 `.lsk` 已保存标注 ID、Double 坐标和照片资产引用，旧文件不会被反向改写。

## 编辑契约

- Android 画布宿主不拥有可变标注集合，只向共享 Compose Canvas 提供 Editor 的只读绘制状态。照片位图与工具触控分派仍在 Android；字体度量与单行字形绘制通过独立 Android 字体适配器提供。归一化坐标到显示矩形的映射、尺寸线/端线/斜刻线、面积填充/轮廓、面积预览、角度射线/小角圆弧/预览及尺寸/角度/面积选中控制点已接入共享 UI，屏幕、放大镜和导出复用同一绘制函数。
- 工具身份 `AnnotationMode` 在共享核心定义；共享 Compose `AnnotationToolbar` 显示宿主当前工具并发送切换意图。工具切换继续经过宿主 `setEditorMode`，保留单次/连续放置、选择清理与属性面板行为。共享 `PlacementOptions` 展示单次/连续状态；单次创建完成后进入移动模式并保留新标注选择，连续创建保留当前工具。移动模式隐藏选项但保留 48 dp 栏位，页面重建保留连续设置。
- `AnnotationActions` 共享完成/删除浮动入口：完成按钮在放置模式显示，进入移动模式；删除按钮仅在移动模式有选中标注时显示。删除立即更新共享文档，平台在页面暂停时将确认文档保存；按钮沿用 52 dp 圆形尺寸及删除位置向下偏移 64 dp 的布局。返回、图片分享、保存相册通过宿主平台回调执行。
- 共享 `ColorPalette` 接收当前选中标注的 ARGB 颜色与平台色样。文字、尺寸、角度和面积使用同一颜色入口；未知颜色保持没有色样选中，空选择禁用。外部选择刷新不发送颜色命令，修改颜色只更新原实体的颜色属性。
- 文字和角度输入由共享 `AnnotationLabelProperties` 显示。宿主持有带光标的输入草稿，选择时把光标放到末尾；刷新选择及光标移动不能产生文档修改。文字内容按原输入保存，角度标签沿用去除两端空白的行为。点击画布或收起面板时清除输入焦点并隐藏键盘。
- 尺寸与面积共用 `AnnotationQuantityProperty` 输入数值与单位；共享 `AnnotationQuantityLabel` 保留旧标签拆分与组合规则。程序性刷新、光标移动和重新选择当前单位不写文档，单位切换不做数值换算；输入清空保存为空标签。近期测量填入时仍使用毫米标签。共享测量仓库到近期列表、默认尺寸及选中尺寸填入均保留 Double，不能先转 Float；显示沿用一位小数，距整数不足 0.05 mm 时省略小数，负值按小数绝对值判断，整数格式不经过 Int。旧 Intent 的 Float 数组只在兼容入口扩为 Double。
- 共享 `RecentMeasurements` 按宿主顺序显示最多三个近期测量，仅尺寸选择时显示；点击由宿主填入毫米标签。共享 `AnnotationAreaPointAction` 仅选中面积顶点时显示，删除仍执行共享命令；三点面积删除失败不改文档，提示由 Android 资源提供。
- 修改标签、颜色、大小或线宽时，只更新对应属性，不能经过 Float 投影重建未改变的 Double 坐标。文字大小、白底与尺寸线宽已由共享 `AnnotationStyleProperties` 展示，显示状态来自宿主选中标注的只读投影；属性刷新不发送编辑命令，点击后宿主调用共享实体的更新命令，再刷新被接受的属性值。单位下拉框的程序性刷新不能修改标签，只有用户改变单位或输入内容才更新文档。
- 创建、属性修改和删除使用共享命令；命令失败不留下部分状态，无变化不写历史、不清除 Redo。撤销/重做只保存变化的实体与必要顺序，不保存照片或每步完整文档。
- 移动模式下按下选中标注并开启预览事务；超过原有像素阈值才移动。整体移动按手势起点的绝对位移计算，连续 MOVE 不累加位移。
- 整体移动保持各点相对形状，整组限制在照片边界；控制点单独调整时限制到 `[0,1]`。从旧文件载入的超范围有限坐标保留，跨度超过照片范围时不能因夹取区间无效而崩溃。
- 面积边的中点可以插入新控制点，包括最后一条闭合边；三点面积不能删除顶点，删除失败不修改状态。
- 抬手把整次拖动提交为一条历史；取消恢复手势之前的文档，不能留下临时位置。普通选中点按不产生撤销记录。
- `AnnotationActivity.onPause` 先调用 `cancelGesture()`，再生成预览和保存，未确认的拖动不能进入持久化文件。
- `ImageAnnotationView.undo()` 现在撤销共享历史中的最近操作，可撤销属性、删除与移动，不再仅删除最后一条尺寸线。当前工具栏尚未增加新的撤销/重做入口，后续共享 UI 使用编辑器 API。

## 验收

1. 尺寸、文字、角度、面积及样式从旧状态转换到共享文档，再转换回来，合法状态完全相等。
2. 拖动尺寸主体，先移动一小段再移动更远，终点位置由最后指针相对起点的位移决定；一次撤销恢复原标注，不能有第二条拖动历史。
3. 拖动后取消或页面暂停，原坐标与标签恢复，且没有撤销记录。
4. 普通点按选中没有历史；改标签后撤销恢复原文字。
5. 面积在闭合边增加中点，删除新增点可以恢复原三角形；直接删除三角形顶点失败。
6. 删除标注后撤销恢复原绘制顺序。调用方之后修改其传入的顶点列表，不能改变 Editor 或历史中的面积。

共享测试覆盖命令、预览事务、范围与历史。Android 仪器测试覆盖实际触控、Canvas、放大镜、单次/连续放置、取消和页面暂停的保存边界。照片读取、分享与文件格式仍通过平台实现，不能用几何单元测试替代这些集成验证。

## 当前共享绘制边界

`PhotoDrawingViewport` 将照片归一化 Double 坐标映射到显示矩形，保留旧工程中超范围但有限的点，不夹取原文档。`dimensionDrawingLayout` 生成尺寸主线、两条垂直端线和两条 45°斜刻线，屏幕处才转 Float；端线半长为 `max(21,16×scale)` px，斜刻线半长为 `max(12,9×scale)` px。细/中/粗线宽分别为 `max(2,1.4×scale)`、`max(3,2.4×scale)`、`max(5,4×scale)` px，保留圆端帽；重合端点仍可绘制端线和刻线，不因归一化零向量而失败。尺寸文字的位置、旋转和白底使用共享标签布局；字体度量和单行字形由 Android 字体适配器注入。

`areaDrawingLayout` 提供闭合顶点及顶点算术平均的标签基线位置；面积填充透明度固定为 48/255，颜色 RGB 与标注一致，轮廓宽为 `max(3,2.4×scale)` px。正在创建的面积只画开放折线和控制点，不填充、不连接末点到首点。控制点半径为 `max(9,7×scale)` px，白色光晕增加 `max(3,2×scale)` px，选中面积顶点沿用橙色，其余沿用宿主注入色。所有绘制产品临时生成，不能修改共享文档或照片。

Android `AndroidCanvasDrawing` 是通用原生 Canvas / Compose DrawScope 适配器，供草图位图导出及照片标注复用。字体字形与照片位图保留 Android 适配，完整 Compose 标注画布和照片放大镜已接入共享 UI；工具触控状态和页面容器仍需继续收拢，且新增画布路径尚待设备验收。

`angleDrawingLayout` 在照片映射到屏幕后计算两射线及小角圆弧，圆弧扫角保留在 `[0,180]`。半径为 `max(较短屏幕射线长度×0.32,22,16×scale)` px，标签基线位于该小角平分线上，距顶点 `半径+max(20,14×scale)` px；不能以归一化照片中的角度代替非等比例屏幕映射后的角度。射线和圆弧沿用 `max(3,2.4×scale)` px 线宽及圆端帽。重合端点保留最小圆弧半径且不崩溃，不推算或改写用户输入的角度标签。角度预览只连接首个点与顶点并显示控制点，未完成时不画圆弧。角度标签已接入共享基线/白底绘制及字体适配，屏幕、放大镜及图片导出共用同一角度形状绘制。

`AnnotationLabelLayout` 统一尺寸、文字、角度和面积的基线、白底及旋转，`drawAnnotationLabel` 只生成临时绘制结果。字体度量通过 `AnnotationTextPainter` 注入；Android 实现只持有 Paint，使用原 `DEFAULT_BOLD` 的字宽、ascent/descent 和单行 drawText 语义，不持有 Activity、文档或照片。标签原始内容不被改写，含换行字符的旧文字继续使用原生单行字形语义。

文字小/中/大档为 `max(18,17×scale)`、`max(22,22×scale)`、`max(28,28×scale)` px，空白文字使用宿主本地化占位文案。文字白底水平和垂直均留 `max(8,6×scale)` px；面积白底垂直边距取该值的一半。尺寸标签字号为 `max(24,18×scale)` px，旋转到可读方向，基线距尺寸线为 `-max(13,10×scale)-descent`，白底垂直边距为水平边距的一半。角度标签字号为 `max(22,18×scale)` px，白底边距为 `max(7,5×scale)` px。白底透明度保持 225/255，文字的白底可关闭，其他标签显示白底。占位文案、空照片提示、角度后缀、颜色和提示字号均由 Android 资源提供。


`drawAnnotationScene` 保持面积、尺寸、文字、角度的类型图层顺序，同类型按文档顺序绘制；正式标注不被临时 ID 重名的预览替换。屏幕的尺寸预览位于正式图层之后，照片放大镜的尺寸预览位于正式尺寸之后、文字之前，沿用原顺序；放大镜不显示选中控制点及未完成面积/角度。导出不显示任何预览或选中控制点，不改变原照片和文档。

共享 `AnnotationCanvas` 绘制背景、照片、标注与放大镜，Android `ImageAnnotationView` 通过 AbstractComposeView 承载，不再维护原生 onDraw。照片按原规则完整适配画布、水平居中和顶部对齐；尺寸显示比例为 `max(1,显示照片宽度/500)`。空照片提示使用宿主文案及字体适配，仍按画布中心定位。非固定高度容器中保留原 360 dp 的期望高度，固定约束优先。

照片放大镜保持 12 dp 边距、最大 128 dp 直径，受画布可用宽高限制；不足边距时隐藏。镜片在右上角，焦点经固定 2.35 倍变换精确映射到中心。照片与标注先经过同一变换和圆形裁剪，再绘制宿主注入颜色及尺寸的边框、十字线；不能放大边框或把裁剪外照片带入画布。


工具模式和选择的唯一来源是共享 `AnnotationEditorState`。选择使用实体 ID 和可选顶点索引；Android 只派生旧界面所需的各类型索引，不能再维护独立的可变选择。选择及工具切换不产生文档历史、不消耗 Redo；切换到另一工具先取消预览，再按显式 `preserveSelection` 决定是否保留仍有效的选择，重复选择当前工具保持原行为。删除/撤销/重做、预览确认及取消后不得留下不存在的实体引用；越界顶点退回实体选择，文档恢复清除选择但保留当前工具。删除面积顶点后 Android 按原行为选择原索引或剩余末点，不能因核心清理越界点而改选其他实体。


创建预览由共享 `AnnotationCreationState` 持有。尺寸按下记录归一化起点，移动仅更新预览终点，抬手使用最后指针位置；屏幕长度严格大于宿主提供的 12 dp 阈值才创建，短拖动或等于阈值时清除尺寸预览且不写历史、不消耗 Redo。预览标签保持空白，确认时使用宿主默认标签与颜色，不能把显示坐标回写到正式文档。画布无可用照片矩形时触控适配直接拒绝，不能产生非有限坐标。

角度依次记录“端点、顶点、端点”，面积按点击顺序记录三角形；前两点仅保存在创建状态，第三点通过共享命令一次提交，成功后清空对应点列并选择新实体 ID。角度前两点清除旧选择，面积前两点保留旧选择，沿用原交互。文字位置、内容、样式默认值及创建后选择也由共享编辑器处理。点击点限制在照片范围，正式几何保留 Double；连续创建产生独立实体。重复/空 ID 的提交失败不消耗点列、不改文档或历史，可以用有效 ID 重试。

切换到另一工具及恢复文档清空全部创建状态，重复选择当前工具保持原状态。取消尺寸指针手势清除本次尺寸预览；角度/面积 ACTION_CANCEL 或页面暂停不追加取消中的点击，先前已完成抬手确认的点击仍可继续，且不进入保存文档或导出。此处点列是创建状态，不能与编辑现有实体的预览事务混为一谈。


共享 `AnnotationDrag` 是现有标注拖动的唯一状态来源：目标为稳定实体 ID 与可选控制点，起点为归一化照片坐标；Android 不再保存移动类型、列表索引、屏幕起点或 started 镜像。核心依据宿主提供的 4 dp 像素阈值判断启动，严格大于阈值才启动；启动后返回起点或边界夹取无变化也保持启动标记，抬手若文档最终无变化则不写历史、不消耗 Redo。没有经过 MOVE 启动的普通抬手不移动，沿用原行为。

整体拖动将原始、可越出照片的指针转换为归一化坐标，按原手势起点计算绝对位移；不能先夹取指针再移动。控制点只夹取目标点，并保留未修改的 Double 坐标及同一预览内的其他属性修改。Android 只在首次启动时通知隐藏属性面板，控制点拖动显示放大镜，整体移动不显示。一次抬手提交整个预览，取消、页面暂停、工具切换和恢复丢弃预览并清理拖动。删除拖动目标或使控制点越界不得保留悬空拖动；拖动目标不能随其他选择或旧列表索引改变而换成另一个实体。


照片标注命中由共享 `AnnotationHitTest` 负责，不通过 Android Float 投影重建几何。Android 提供归一化指针和照片显示宽高，以及资源中的像素容差：尺寸/角度射线 32 dp、文字锚点 44 dp、已选尺寸/角度控制点 28 dp、面积顶点 44 dp、面积边 28 dp。归一化点不夹取；宽高分别缩放像素距离，不能把非正方形照片当作等比例坐标。角度只命中两条有限射线，不把圆弧或无限延长线当成标注主体；文字沿用锚点容差，不改为字形包围盒。

命中顺序沿用原交互：已选尺寸/角度控制点优先；面积顶点先检查已选面积，再按反向文档顺序检查其他面积；其后依次为文字、尺寸线、角度射线、面积主体。文字/尺寸/角度同类型选最近对象，同距保留最先文档项；控制点同距保留最小索引。面积主体按反向文档顺序检查边线或真实多边形内部，不能用包围盒代替凹多边形；边线含闭合末边，同距保留最小边索引。命中是只读操作，不修改文档或历史，不在宿主另维护几何选择算法。


面积边双击状态由共享 `AreaEdgeTap` 持有，不再保存 Android 面积列表索引。首次点击记录实体 ID、边索引、原始端点及事件时间，未超出 450 ms（包含边界）的第二次同边点击才插入中点；超时、时间回退、其他实体或其他边都重新开始一对点击。Android 提供 MotionEvent 的单调事件时间及资源窗口，不读取系统日期时间判断手势。时间零是合法值，不能兼作“没有第一次点击”的哨兵。

目标被删除、端点变化、顶点索引失效或恢复文档会清除待确认边，避免第二次点击插入另一条边；标签等非几何属性修改保留原点击。同一编辑器切换工具时仍沿用原窗口，不把待确认点击写入文档或撤销历史。成功插点选择新顶点并清空待确认状态；若释放事务已开启，则插点仅修改预览，由这次抬手提交一条历史，取消仍恢复原文档。中点对普通值保持原平均规则，对有限极大旧坐标使用防溢出平均，不把合法有限几何变成非有限点。


共享 `AnnotationScreen` 保持页面容器规则：工具栏、放置选项先占据内容高度，照片画布填满剩余空间；侧边动作在画布内垂直居中，距右边 12 dp。属性面板距画布边缘 10 dp，显示、隐藏与编辑内容增高只覆盖照片，不能重新缩放或移动照片视口。侧边动作绘制和命中在属性面板之上，即便高属性面板与按钮位置重叠，完成/删除仍可触达，点击不能落到下面的属性或画布。系统栏 Insets 继续由 Android 宿主适配。属性浮层由共享 `AnnotationPropertySheet` 承载，不再使用原生 LinearLayout 或逐项 ComposeView；系统键盘由 Android 适配，属性输入的焦点清理由共享组件响应宿主信号。页面容器不负责编辑器选择或文档历史。

自动填入使用共享记录 ID 判断新增：初次加载及相同 ID 快照刷新不能覆盖手动标签，删除/清空不填入。新增同值记录拥有新 ID，仍按一次新增更新当前尺寸；近期列表达到上限时只允许移出末项的单次新增。多条历史整体替换不猜测为一次设备采集。


属性浮层手柄高 24 dp，滑条为 42×4 dp；浮层水平/垂直内边距 12/10 dp，圆角 14 dp，阴影 10 dp，沿用原背景和手柄资源颜色。手柄按下即接管指针，不等待拖动 slop；距离使用根坐标，防止同一帧连续 MOVE 或浮层自身平移累加位移。向上拖动夹为零，透明度为 `max(0.45,1-距离/高度×0.55)`。抬手及取消时距离达到 56 dp 即请求收起，否则以 140 ms 回到初始位置和透明度。收起用 180 ms 移动至自身高度加 20 dp 并淡出，结束才移除内容；新选择即使在动画中也立即取消旧动画并复位。取消选择立即隐藏。收起只清理输入焦点和展示状态，不能删除共享选择或产生文档历史。


照片坐标双向映射由共享 `PhotoDrawingViewport` 提供。屏幕到归一化坐标的减法与除法使用 Double，不能先在 Android Float 中做差再扩精度。创建时显式夹取归一化坐标，拖动/命中使用原始越界坐标；零宽或零高布局不接受映射输入。


Android 提示通过 `AnnotationNotice(text, showToast)` 显式传递展示策略，不按本地化文案的前缀推断行为。面积第一次放点弹 Toast、第二次放点和完成仅更新提示；角度两次放点与完成均弹 Toast；文字/尺寸创建及移动/删除仅更新提示。用户文案取自 Android 字符串资源，翻译不能改变提示时机。

# 移动端轻量几何核心

所有引擎坐标和尺寸使用毫米与 `Double`。旋转角属性使用度，数学角函数使用弧度。UI 的 px、dp 和触摸容差在平台入口转换。

## 分层

- `Geometry`：向量、距离、投影、交点、偏移、凸包，不认识墙、UI 或撤销。
- `WallGeometry`：定位线生成中心线、边线和多边形，计算墙角延伸；这些都是派生数据。
- `WallNetworkGeometry`：从各墙定位线和实体生成包角、斜交 T 端部多边形。显示最小半墙宽由 UI 转成毫米传入；不包含屏幕缩放和像素类型。
- `OpeningGeometry`：毫米偏移、宿主边界、固定端距离、门窗图形线段。
- `ColumnGeometry`：旋转矩形角点与命中、圆柱命中、角度归一化。
- `HitTestEngine`：把纯几何结果映射到对象 ID；通过 HitTestContext 在核心内统一定位端点、门窗、柱和墙身优先级及各自容差；平台只提供旋转柄命中 ID。
- `UpdateWallsCommand`：整组墙与门窗修改的原子有效性；失败时不产生文档。
- `WallEditPlanner`：共享端点联动与 T 附着规划；数学内部交点不会自动变成节点。
- `SnapEngine`：端点、控制线、中点、交点、网格、轴向、角步进、柱中心和墙面对齐。Android 保留原有吸附启用项与屏幕容差。

零方向不可归一化或偏移；最近点允许退化线段并返回起点。平行、共线重叠及退化直线没有唯一交点，返回 null。共线重叠不自动生成拓扑连接。

通用数值 epsilon 为 `1e-9`；近似平行判断用相对方向长度的角容差 `1e-5`。旧 Android 兼容外观保留原绘制交点的绝对阈值和短墙规则。门窗宿主边界容差为 `0.01 mm`，以适配原 Float 文件与绘图状态；不能用屏幕缩放改变数据有效性。

## 回归要求

- 45°至180°墙角使用延伸连接，105°不能折算为75°。
- 斜交 T 墙的两侧角分别延伸到宿主远侧面。
- CENTER/LEFT/RIGHT 保持定位线；改变长度或厚度不能移动固定定位点。
- 改变宿主墙起点时门窗保留到终点的距离；改变终点时保留到起点的距离。
- 一面关联墙无法容纳门窗时，整组编辑失败，历史和所有实体不变。
- 柱与门窗按实际几何命中，不能恢复为过大的圆形触摸范围。

引擎只处理移动端轻量草图，不引入布尔内核、约束求解器、BRep/NURBS 或 BIM 生成。桌面应消费语义文档并独立构造重型几何。

网格索引使用 Double，不经过 Int/Long 窄化。半格保持向正无穷舍入，例如 +150 mm→+200 mm、-150 mm→-100 mm（步长 100 mm）。计算按整数部分与小数部分分开判断，避免对大整数直接加 0.5 引入移动。若有限坐标与合法步长的商或网格乘积无法表示为有限 Double，该轴保留原坐标；不生成无穷坐标、异常或 Int 饱和值。
